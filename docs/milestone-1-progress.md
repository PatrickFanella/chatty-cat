## Channel discovery and chatter lists (#14)

Channel discovery offers live followed channels, all followed channels and chatters for a joined channel. Optional `user:read:follows` and `moderator:read:chatters` grants are requested separately through explicit Twitch consent links; ordinary chat login does not request them. Existing optional grants survive a later consent flow. API requests derive the account and moderator identity from the opaque server session, never a browser-supplied user ID. Twitch enforces the chatter channel role. Follow state remains separate from the native video iframe login.

Every explicit load returns one page of at most 100 rows. Search filters that page, Next replaces it, and the panel labels observation age, reported total, pagination and missing permissions. Chatter membership may lag and is explicitly distinguished from viewers. No automatic refresh runs. The server allows at most 20 discovery requests per session per minute, shares the existing concurrent request limit and honors provider rate-limit reset times. Tokens and upstream error bodies remain server-only. Pages are memory-only, use no-store, and are cleared on account/permission changes or privacy mode. Pending reads are aborted and stale replies cannot repopulate another account. Joining uses the existing channel admission/layout reconciliation and pending-send guard, preserving drafts and the saved workspace lifecycle.
