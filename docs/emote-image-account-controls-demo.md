# Emote image controls and account selector action

Provider and badge preferences has independent chat emote-image, animation and zero-width layering switches. Images and layering default on, animation retains its existing on default, and older preferences receive additive defaults. Turning images off creates ordinary name text without emote image elements or collapsed visual spacing; it does not change provider catalogs, source messages or native tag ranges. Bits images/amounts and the separately selected Unicode emoji style remain independent. Disabling layering renders zero-width assets as ordinary adjacent emotes rather than hiding them. Disabling animation selects static assets; missing static assets use the existing labelled text fallback.

Tagged native Twitch emotes now use the explicit static CDN format rather than default for their static fallback, matching the [Twitch emote template contract](https://dev.twitch.tv/docs/api/reference/#get-global-emotes). Catalog/account static URLs already used that format. This correction also applies to frozen native-tag rendering.

The configurable Open account profiles action defaults to Alt+KeyA and is searchable in the action palette. It asks the existing account controls to open, with the same privacy guards. It does not switch, sign out or grant permission. Actual account changes retain the existing explicit user action and Twitch consent. The shortcut keeps the standard editable/IME/modal guards and participates in portable shortcut preferences.

Reproduce with the built provider fixture at http://127.0.0.1:5192/?channel=current&video=off. Review/apply images off and inspect the original Wave/Overlay/Kappa names with no ordinary emote image nodes. Re-enable images, disable zero-width layering and animation, then inspect separate assets and the native /static/ URL. Close the dialog, focus chat and press Alt+A. Account profiles opens while the signed-in identity stays unchanged.

Native T3 preview verified these steps on 2026-10-13: zero ordinary emote images with the name text retained, the independent cheer image retained, zero overlay nodes after disabling layering, the explicit native static URL, the account selector open with Sign out still shown, and zero fixture provider writes. Unit coverage includes retained native ranges, independent controls, static fallback, account-action dispatch/cleanup, privacy and shortcut guards. Full checks are recorded in the PR.
